# 新人优惠券

`CouponModule` 导出 `CouponGrantService`。注册不自动发券，用户注册后七天内通过领取接口主动领取。
领取事务内重新检查资格，用户优惠券和发放流水共同提交。接口说明见
[新人花礼用户接口](../marketing-activity/new-user-gift.md)。

- 使用 `trigger = NEW_USER` 的营销活动关联的优惠券模板。
- 活动未配置、未启用，或模板、兑换规格、兑换商品停用时拒绝领取并返回原因。
- 奖励配置异常时拒绝领取，不影响注册。
- 复制模板与活动快照，金额保持数据库的元单位；有效期从发放时刻起计算。
- `grantKey = new-user:{userId}` 唯一标识新人奖励，重复调用返回原券，不修改快照、
  不延长有效期；发券流水使用 `issued:new-user:{userId}`。
- 已有用户再次登录、补充 openId 和测试登录不会触发新人发券。

本模块当前实现新人发券；邀请奖励、用户券列表和用券流程后续在此扩展。
数据库沿用现有表结构，无需新增迁移。
