# 新人优惠券

`CouponModule` 导出 `CouponGrantService`，微信手机号首次注册时调用
`grantNewUser(userId, tx)`。事务由 `UserAuthService` 开启，创建用户、邀请关系、
用户优惠券和发放流水共同提交；数据库写入或配置校验失败时共同回滚。
微信接口请求在事务之前完成，登录令牌在事务成功之后签发。

- 使用 `trigger = NEW_USER` 的营销活动关联的优惠券模板。
- 活动未配置、未启用，或模板、兑换规格、兑换商品停用时跳过发券，注册正常完成。
- 奖励已启用但金额、份数或有效期等规则异常时返回配置错误，注册回滚。
- 复制模板与活动快照，金额保持数据库的元单位；有效期从发放时刻起计算。
- `grantKey = new-user:{userId}` 唯一标识新人奖励，重复调用返回原券，不修改快照、
  不延长有效期；发券流水使用 `issued:new-user:{userId}`。
- 已有用户再次登录、补充 openId 和测试登录不会触发新人发券。

本模块当前实现新人发券；邀请奖励、用户券列表和用券流程后续在此扩展。
数据库沿用现有表结构，无需新增迁移。
